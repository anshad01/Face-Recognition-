# 🎓 Face Recognition Attendance System

A smart attendance tracking system using face recognition built with Streamlit, OpenCV, face_recognition, and dlib. The app captures faces via webcam, marks attendance in an Excel sheet, and tracks student absentees day by day.

---

## 🚀 Features

- Real-time face recognition using webcam
- Attendance stored in Excel files (`Attendance_dd-mm-yyyy.xlsx`)
- Duplicate attendance prevention
- Trained person tracking as students
- Daily absentee identification
- Attendance dashboard (College Data page) to view and analyze logs

---

## 🛠️ Tech Stack

- **Frontend**: [Streamlit](https://streamlit.io/)
- **Backend**: Python, [face_recognition](https://github.com/ageitgey/face_recognition), [OpenCV](https://opencv.org/)
- **Storage**: Excel files (`.xlsx`) using `pandas` and `openpyxl`
